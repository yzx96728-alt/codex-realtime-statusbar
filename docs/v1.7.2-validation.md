版本1.7.2／build10，基于本地未提交的1.7.1候选继续修改，仍在原分支。原1.7.1差异补丁及其事件测试已保留于忽略的本地构建目录。没有提交、推送、发布、替换正式安装或修改Codex配置；候选独立输出至`build/v1.7.2/`。1.7.1修复依据和数据限制见[v1.7.1验证](v1.7.1-validation.md)。

## 实现范围

- 统一入口`安装或升级.command`复用构建、打包和独立技能安装器。包内逐文件SHA256校验、签名／标识／版本校验；检测运行中副本、标准路径和主目录Spotlight索引，也可明确指定旧路径。多份应用由用户选择，其他运行副本阻止替换。无管理员提权；标准应用目录不可写时明确询问用户目录。
- 先正常退出旧进程，验证完整备份，再暂存与替换；失败尝试恢复。安装器只删除自己创建的暂存目录及已验证备份的旧应用副本。备份在用户Library的专用目录，权限受限；不会删除设置、其他技能或聊天资料。
- handoff沿用官方与传统技能目录、CODEX_HOME；必要文件相同跳过，附加文件保留。不同视为可能自定义，确认后完整备份到扫描目录外。无单独技能版本时按内容核对，不虚构版本。多份同名暂停技能更新，应用结果与技能结果分别报告；技能未更新不能视为整套成功。
- SMAppService.mainApp登录项由用户明确选择，回车保留现状。菜单读取系统状态，不在启动时自动重新注册。隐藏时停止定时刷新，激活／启动／退出／唤醒事件恢复，睡眠暂停；原有位置、语言和设置不变。待命时菜单栏入口可管理登录项或退出。没有运行中的监控进程，不能由Codex自动唤起；没有额外守护进程。
- 65%仅橙色，点击查看建议；70%正常完成且新鲜用量符合现有门控才展示非激活浮动提示。标题加粗，主要按钮“准备交接”，次要按钮“暂不交接”；无声音或闪烁。只复制并返回锁定来源，由用户发送。可继续工作，阈值不宣称成本最优。已显示提示也绑定用量事件，压缩、取消、新请求、降至70%以下及过期后关闭。

## 授权与签名核验

对比本机稳定版与1.7.1候选签名：Bundle ID相同，指定要求均由两个架构的CDHash组成，代码哈希不同。这是Ad-hoc升级无法保证授权复用的实际证据，不能仅凭Bundle ID声称已解决。

保留固定Bundle ID、推荐标准路径，不改TCC、不重置授权、不使用更宽松的签名指定要求。原跟随逻辑额外依赖本地`followAccessConfirmed`标记，现直接检查AXIsProcessTrusted，避免系统授权有效但本地标记缺失时误报。升级后输出实际信任状态；需要时用户选择打开“系统设置 → 隐私与安全性 → 辅助功能”，由用户亲自授权。回到Codex重新检查，不默认重启。若系统仍拒绝，用户可重启最终同一份应用，必要时手动移除／重新添加权限。

可选`SIGNING_IDENTITY`支持构建者已有的证书，默认Ad-hoc；没有创建证书或购买账号，未验证证书升级的授权复用。原理依据：[Apple代码签名与指定要求](https://developer.apple.com/library/archive/technotes/tn2206/_index.html)、[SMAppService.mainApp](https://developer.apple.com/documentation/servicemanagement/smappservice/mainapp)。固定路径能减少路径变化，但并非免授权保证。

## 未验收与人工步骤

未覆盖稳定版安装，未在本机登记候选登录项或更改系统授权。此前电脑操作访问本应用被拒绝；本轮不绕过限制。因此以下GUI及系统行为**没有实测通过**，不能用编译／逻辑测试代替：

1. 批准候选安装后，在最终路径检查正常退出、单实例、登录项开关及实际系统状态。将旧自定义路径迁到标准路径时需额外检查登录项，路径变化可能需要用户重新启用；回车“保留”不会强制重新注册。
2. 有效授权直接跟随；无效时手动授权后切回Codex，若仍失败再重启同一份应用。Ad-hoc跨版本授权复用尚未实测，可能仍需重新添加。
3. 登录时Codex已开／登录后再开、关闭重开、频繁切换其他应用、睡眠唤醒；观察隐藏待命与目标更新后显示，且无重复实例。
4. 系统关闭登录项不会被恢复；主动退出不会立即重启；升级前后窗口位置、透明度、语言、选择与提醒状态保留。
5. 65%仅变色；70%正常结束后提示，中文／英文布局、无焦点抢占、两个按钮和锁定来源；压缩／取消／新任务／过期及时关闭。

Intel仅交叉编译，未做Intel实机验证。没有Developer ID公证，下载隔离仍可能被Gatekeeper拦截。完整性哈希不是发布者身份认证。日志仍按变化全量分块扫描、单行上限16MiB、自动／手动压缩不可区分，延续1.7.1已记录限制。
