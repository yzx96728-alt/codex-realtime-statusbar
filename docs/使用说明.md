# Codex实时状态栏 1.7

双击本目录的 **Codex实时状态栏.app** 启动。切到其他应用时隐藏，返回 Codex 后重新识别聊天并恢复。仍保留 348 × 30 的默认尺寸、42% 透明度及已有位置记忆。

## 点击查看

- 点击 token：累计与最近请求的输入、缓存输入、输出、思考 token。总量为输入 + 输出；思考是输出的细分，缓存是输入的细分，不重复相加。
- 点击缓存：累计和最近请求的缓存输入 / 输入及计算口径。
- 点击上下文：最近请求总 token / 记录窗口容量的估算、记录时间及交接按钮。
- 所有详情卡显示完整聊天名称和记录时间。额度为该聊天 token_count/rate_limits 中的历史快照，可能已经变化，不能当成实时余额。
- 点击外部关闭详情卡，不扩大常驻浮窗。↪ 表示自动跟随，⌖ 表示固定监控。

## 轻提醒

默认开启，可在 ⋯ 菜单关闭。65%首次提示、70%再次提示，便于在合适阶段准备交接并为整理材料预留空间；不是官方质量或费用分界。仅新写入、两分钟内的用量记录可触发；首次读取已有记录不主动提醒。达到 65% / 70% 时变色，待结构化 task_complete 事件确认本轮结束后展示安静提示。不发声、不激活输入框。任务仍在进行、状态不明或记录过旧时不弹出。

每个聊天、每个档位只提示一次，状态跨重启保存。估算降至 55% 以下后重新允许提醒。一次跳过多个档位时只提示当前最高档位。估算仅供参考，不代表必须换聊天。

## 交接入口

在上下文详情或提醒中点击按钮：

1. 以卡片中的聊天标识、名称、原工作目录锁定操作目标。
2. 复制完整 `$handoff` 指令，并校验剪贴板写入。
3. 用 `codex://threads/<id>` 返回指定聊天，提示“指令已复制，按 ⌘V 后发送”。

**需要你粘贴并发送才执行。** 小窗没有编辑输入草稿、发送消息、创建聊天或生成摘要的实现。交接由 Codex 依当前模式及现有 handoff 技能执行，指令包含保存并核对状态、决定与权限边界、同原目录建立接续聊天、先核验再继续、保留来源等要求。没有可靠标识或可核验目录时按钮禁用并说明原因。

菜单“返回上次交接来源”只记录上次准备指令的来源，不表示交接已经完成。

命令参考：[开发者命令](https://learn.chatgpt.com/docs/developer-commands)、[聊天链接](https://learn.chatgpt.com/docs/reference/commands)。

## 跟随、显示和设置

自动跟随沿用 1.4 已验证的主窗口与唯一标题匹配；明确标识优先，同名或识别失败时不猜测。切到其他应用后暂停界面识别，隐藏浮窗、卡片和选择器；回到 Codex 先刷新监控目标。操作自己的菜单、详情卡或聊天选择器不会触发离开隐藏。本版不判断 Codex 内部首页或设置页。

手动选择聊天切换为固定模式，并展示提示。要恢复跟随，在 ⋯ 菜单开启“自动跟随当前聊天”。透明度和位置均保存；默认仍为 42%。

权限失效时小窗明确显示“需授权自动跟随”，从 ⋯ 检查当前这份应用的辅助功能权限。系统列表开关为开不一定代表新版签名有效，需以小窗实际识别成功为准。

## 本地数据和 token

监控只读取本地聊天目录索引、结构化用量/任务事件和 Codex 窗口顶部元数据。不截图、不 OCR、不上传、不启动后台模型或新服务，日常监控不消耗模型 token。你粘贴发送交接请求后，Codex 的实际处理产生正常用量。

## 更新与本地备份

构建后先完成整包签名，再更新辅助功能授权；验收期间避免反复替换二进制。本仓库不包含维护者的本机应用备份、聊天数据或授权状态。更新前可自行备份当前版本。

## 界面语言

在 `⋯ → 语言 / Language` 选择“简体中文”或“English”。切换立即生效，重启后保持；聊天名称不翻译，监控目标、用量、提醒与原有权限不重置。交接指令会随所选语言变化。系统自带对话框按 macOS 语言显示。

## 安装随附的通用交接技能

下载包解压后包含应用、`skills/handoff`、`安装交接技能.command` 与中英文说明。技能为社区提供，可独立使用，没有计数器、Hook、Python 或后台服务。

将安装脚本与 `skills` 保持在同一目录，双击 `安装交接技能.command`。首次安装使用 `~/.agents/skills/handoff`；发现既有用户安装（包括传统 `~/.codex/skills` 或 `$CODEX_HOME/skills`）则沿用原位置，确认后先把旧版完整备份到 `~/.codex-handoff-backups` 再替换。发现多份声明为 `handoff` 的技能时停止并列出位置，需先自行选择保留哪一份。脚本不会更改 Codex 配置、权限或 Hook。

若系统阻止下载的脚本，可手动复制随附的 `skills/handoff` 到 `~/.agents/skills/`，无需降低系统安全设置。先检查传统目录与同名技能，替换前备份到技能目录之外，只保留一份安装。其他系统可把这个纯指令技能手动安装到宿主支持的技能目录；小窗和 `.command` 脚本仅适用于 macOS。

安装后在 Codex 输入 `$handoff`；若没有出现，请重启 Codex。单独输入只保存进度；明确要求“保存、在原目录新建并打开聊天、核对后继续”才进行完整交接。技能按用户语言工作，有聊天管理工具时自动创建并核验接续聊天；缺少工具时交付材料与可复制的开场指令。Plan 模式只制定方案，不写文件或创建聊天。

## 从旧版升级

保留语言、透明度、窗口位置、跟随／固定选择和来源书签。旧80%／90%提示记录映射为65%／70%，清除旧待弹提醒；升级后首次读取仅建立基线，后续新记录才触发。低于55%才重新允许下一轮提醒。Codex 自行处理自动压缩，小窗已移除手动压缩按钮，不修改自动压缩设置。
